# 灵犀 AI · AI Sales OS 页面原型

直接双击 `index.html` 即可浏览，无需安装依赖。

## 版本快照

- 最新版始终使用根目录 `index.html`。
- 历史版本位于 `versions/v版本号/`，归档后不可覆盖。
- 每次开始新一轮 UI 修改前，先执行 `./archive-version.ps1 -Version 版本号` 保存当前版本。
- 浏览器访问 `versions/` 可查看所有已归档版本。

## 页面范围

- 移动端：企业微信 / 微信会话内 NBA、人工确认、越界转接、CRM 待办
- PC 端：联系人队列、原生会话区、客户画像、购买信号、NBA 卡片、自动待办
- 后台：经营看板、会话、建议记录、跟进任务、知识库、场景策略、质量评测、提示词、客户、CRM、分析、组织权限、渠道集成、安全审计、全局设置

## 设计原则

1. AI 只建议，销售确认后发送。
2. 建议说明意图、证据、置信度与缺失参数。
3. 退款、签约、敏感承诺和超知识范围场景强制转人工。
4. 采纳、修改、拒绝、稍后处理均留痕，用于质量和业务评估。
